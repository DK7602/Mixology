MIXOLOGY - install by hand (this download holds Mixology only; the Sonicology installer does all of this for you)

1. THE PLUG-INS
   Windows  Copy  VST3\Mixology.vst3  and  VST3\Mixology Link.vst3  to  C:\Program Files\Common Files\VST3\
            (Chrome may call the zip "dangerous" because it isn't code-signed yet: choose Keep.)
   Mac      Easiest: use the Sonicology installer (it isn't blocked the way a downloaded zip is). By hand: copy
            the two .vst3 to /Library/Audio/Plug-Ins/VST3/ and the two .component (AU, for Logic) to
            /Library/Audio/Plug-Ins/Components/, then in Terminal clear the download block on each copy, e.g.
              xattr -dr com.apple.quarantine "/Library/Audio/Plug-Ins/VST3/Mixology.vst3"
            (same for Mixology Link.vst3 and both .component); otherwise the DAW calls them damaged.
   Rescan the plug-ins in your DAW. Mixology goes on the Stereo Out / master, Mixology Link on every track you
   want Mixology to hear (the last plug-in on the track).

2. THE TWO MIDI PORTS (only to let Mixology move your DAW's faders)
   Windows  Install loopMIDI (free, tobias-erichsen.de) and add two ports named exactly
              Mixology to Cubase
              Cubase to Mixology
            (the names say Cubase; they work for every DAW).
   Mac      Nothing to do: Mixology makes the two ports itself while it runs (from the moment the project plays).

3. THE BRIDGE FOR YOUR DAW
   Cubase / Nuendo
            Copy the folder  "Cubase MIDI Remote\Mixology"  into
              Documents\Steinberg\Cubase\MIDI Remote\Driver Scripts\Local\
            so you end up with  ...\Local\Mixology\Bridge\Mixology_Bridge.js
            (Mac: ~/Documents/Steinberg/Cubase/MIDI Remote/Driver Scripts/Local/)
            Studio > Studio Setup > MIDI Port Setup: untick "In 'All MIDI Inputs'" for both Mixology ports.
   FL Studio
            Copy the folder  "FL Studio\Mixology Bridge"  into  Documents\Image-Line\FL Studio\Settings\Hardware\
            (Mac: ~/Documents/Image-Line/FL Studio/Settings/Hardware/)
            Options > MIDI settings. Input: pick "Mixology to Cubase", tick Enable, Controller type
            "Mixology Bridge", Port 200. Output: pick "Cubase to Mixology", Port 200 (the same number).
   Ableton Live
            Copy the folder  "Ableton\MixologyBridge"  into  Documents\Ableton\User Library\Remote Scripts\
            (Mac: ~/Music/Ableton/User Library/Remote Scripts/). Restart Live. Settings > Link, Tempo & MIDI: in a
            free Control Surface row pick "MixologyBridge", Input "Mixology to Cubase", Output "Cubase to Mixology"
            (Live 11: Preferences instead of Settings).
   Logic Pro
            Nothing to copy: Mixology acts as a Mackie Control. Press play once; Logic often finds it by itself.
            If not: Logic Pro > Control Surfaces > Setup > New > Install > Mackie Control > Add, then Output Port
            "Cubase to Mixology", Input Port "Mixology to Cubase".
   Cakewalk
            Nothing to copy: Mixology acts as a Mackie Control. Preferences > MIDI > Devices: tick "Mixology to
            Cubase" (Inputs) and "Cubase to Mixology" (Outputs). MIDI > Control Surfaces > Add (the star) > Mackie
            Control, Input "Mixology to Cubase", Output "Cubase to Mixology", OK.
   Other DAWs
            No bridge: Mixology lists every fader move with the exact dB and you set the faders.

4. Open Mixology. In Settings (the gear) pick your DAW; its Bridge tab turns green ("Connected to ...").
   It doesn't? Press Copy log in that tab and send what it says, with a screenshot of the DAW's fader.

Already set up? Only step 1 again: copy BOTH plug-ins from this download. Copy the bridge script again too
when this version's notes say it changed.
The full manual is MANUAL.md (also inside Mixology: the ? button).
