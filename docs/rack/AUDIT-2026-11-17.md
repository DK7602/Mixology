# Sonicology Rack audit, and Rackaholic (2026-11-17)

After Beta 17 (the Rack's freeze fixed), the user asked for: (1) an audit of the Rack and how it talks to Cubase and the
other plug-ins, (2) what would make the Rack better and more useful, (3) a study of Rackaholic, called the #1 vocal
plug-in of 2026 on YouTube, and what Sonicology needs to be the best vocal, mix and mastering suite.

Nothing below is built yet. The build plan at the end waits for the user's go.

## 1. Audit: the Rack's communication

How it works today: every Sonicology plug-in writes what it does into one shared memory block in Cubase's process
(suite/RackLink.h). An open Rack reads it (rack::viewJson) and shows it. Since stage 2 a click becomes a request in the
owning plug-in's queue; the owner applies it like your own mouse move (one host gesture per drag, so Cubase's
automation sees it), and the Rack reads the answer.

### Checked and fine

| What | How it was checked | Result |
| --- | --- | --- |
| Cost of building the Rack's view | Timed, 20 plug-ins, full details | 0.6 ms (shown track) to 1.9 ms (every track) |
| Cost of a plug-in sending its details | Timed, a Mixology Link with 15 modules | 17 microseconds, 5 times a second while a Rack is open |
| Cost of checking for requests | Timed | 0.4 microseconds per check |
| Requests from several Racks at once | Test: 4 senders + the owner on threads, thread checker | Every request once, whole, in order; no data races |
| Shared memory | Measured | 6.1 MB (was 4.3 MB before stage 2) |
| The Rack page's own work | Chrome trace, Beta 15 vs Beta 16 page | About the same (~20 % of one core in software drawing) |
| The windows' 30 Hz meter frames | Read the code | Numbers and short names only: cheap |
| Masterology's IN / OUT in the Rack | Your second video, frame by frame | Correct; "—" only in the first second after opening |
| Locks (Auto-Edit, Auto-Master) | Tests + preview | Knobs read-only with the reason; drags closed cleanly |

### Found

| # | Finding | Effect | Fix | Size |
| --- | --- | --- | --- | --- |
| A1 | **Fixed in Beta 17.** JUCE escapes a native function's text with a step whose time grows with the square of its length; the Rack's data went that way | Cubase froze while a Rack was open | The data is served as a file (rack-data/<track>.json) | done |
| A2 | The old route is still the fallback when the file can't be read, and it is still slow | If the file route ever fails (a Mac, a host we haven't tried) the freeze comes back | Send the fallback in a form JUCE doesn't need to escape (base64 text: no quotes, no backslashes) | done (Beta 18) |
| A3 | Mac not tried: the file route (juce:// scheme) and the AU versions | Unknown | A Mac tester; the fallback (A2) makes it safe either way | test |
| A4 | While any Rack is open, **every** plug-in sends full details 5 times a second, though the Rack only shows one track's | Wasted work that grows with the project (Voxology also measures a spectrum for every vocal) | The Rack says which track it shows; plug-ins elsewhere send the short version | done (Beta 18) |
| A5 | Mixology on the Full Mix checks for requests 10 times a second (the others 25 - 30) | Full Mix knobs feel a little slower | Its faster timer while a Rack is open, as Voxology / Masterology | done (Beta 18) |
| A6 | While you drag, the knob moves at once but its value text updates only when the plug-in reports back (0.3 - 0.5 s) | Hard to land on an exact value | The owner reports back right after it applies a request; the knob shows the plug-in's text sooner | done (Beta 18) |
| A7 | Cubase's own undo doesn't cover plug-in knob moves | A wrong Rack move can't be undone with Ctrl+Z | UNDO / REDO in the Rack (stage 2 step 4, planned) | medium |
| A8 | A knob with automation in Read mode jumps back after a Rack move, with no word why | Looks broken | When a knob snaps back right after a move, the Rack says: "Cubase's automation (R) moves this knob" | done (Beta 18) |
| A9 | Plug-ins of different suite versions can't see each other; the Rack then says "NOT IN THIS PROJECT" | Misleading after a partial update | Detect an older plug-in in the project and say "Update Masterology to this beta" | done (Beta 18) |
| A10 | The Rack opens inside the plug-in's window at its current size (your video: about 970 x 540) | Small text and knobs | Enlarge the window while the Rack is open, back to its size on BACK | done (Beta 18) |
| A11 | Honey Tune's Snap / Drift / Vibrato are for all its clips, but the Rack shows them on one track | Surprise when other tracks change too | Label them "all Honey Tune clips" in the Rack | done (Beta 18) |
| A12 | Voxology's Auto-Edit report, Masterology's Auto-Master report and reference info also go through the slow JUCE path | Fine at today's sizes, a freeze if they grow | Send them the same safe way as A2 | done (Beta 18) |

## 2. What would make the Rack better and more useful

Ranked by value for a mixing novice, using what the Rack can already do:

1. **One-click fixes on the Coach's warnings.** The Rack already spots two reverbs on a vocal, two tuners, Mixology's
   Limiter before Masterology, a vocal Mixology can't hear. Each warning gets a button that makes the fix ("Turn the
   Link's Space off") through the request plumbing, with undo.
2. **The track's fader in the Rack.** The FADER hex in Chain Flow is greyed today. Mixology's bridge already reads and
   moves Cubase's faders: show the fader level (and pan) and let the Rack move it.
3. **Gain staging at a glance.** Each plug-in already reports its in / out level. A level line through the chain that
   flags clipping and big loudness jumps (a plug-in that makes the vocal 6 dB louder sounds "better" just by being
   louder).
4. **Session overview.** One page with every track and its plug-ins' modules (on / off / resting) as a grid; click to
   jump. Spot a missing de-esser or a doubled compressor across the whole song.
5. **Stage 2 step 4 (planned): BYPASS, A/B, UNDO / REDO, SAVE CHAIN.**
6. **Handling:** a bigger window (A10), double-click a knob to reset it, mouse wheel to nudge, type a value.
7. **Stage 2 step 5 (planned): Mixology Link's RACK button, the insert-order check, TURN ON HERE.**
8. **Stage 3: the Coach** (analyse, build, apply through the plug-ins, measured results).

## 3. Rackaholic

### What it is

A modular channel strip released in November 2026 by Rackaholic Audio (one developer, Georgia), $49.99, VST3 / AU,
Windows and macOS. You build a chain inside one plug-in from 26 modules (up to six of each), in any order:

- **Dynamics:** a compressor with 14 styles (Clean, Punch, Opto, Vari-Mu, Vocal, Bus, Mastering...), FET (RK-76), opto
  (RK-2A), a character compressor, a bus compressor, a de-esser with "monitor what is removed", a neural De-noise that
  splits voice, room and noise with a fader each, a true-peak / LUFS limiter, a clipper.
- **Tone:** a 24-band dynamic EQ (mid / side per band, zero latency to linear phase, full-screen editor), Quell (a
  resonance suppressor, like soothe), a tube program EQ, a console EQ, Air, two saturators, distortion.
- **Space:** a delay with 31 styles, two reverbs (63 programs), doubler, chorus, flanger.
- **Pitch and analysis:** scale-locked tune, a polyphonic transposer, BPM / key detection of the whole file.
- **Workflow:** drag to reorder, a preset per module, the whole chain as a preset, 24 factory chains, undo / redo,
  Bypass All, a Low Latency switch, UI scale.

### Why it's being called great

- Everything for a vocal in one window, cheap, and quick to learn: a novice loads "Silk Lead" and is close.
- A lot of character to choose from (compressor styles, delay and reverb programs), hardware-style looks.
- The neural voice / room / noise faders, the 24-band EQ and Quell are tools people normally buy separately.

The "#1 vocal plug-in of 2026" claim comes from launch videos. There are no independent reviews yet: no KVR user
reviews, no forum threads, and the developer's site has no CPU figures or sound comparisons. Some of those launch
videos may be paid promotion; we can't tell.

### Where Sonicology is ahead

Rackaholic is a very good box of tools. It has no idea what the rest of the song is doing. Sonicology does:

- **It listens and decides.** Auto-Edit sets the whole vocal chain from what it hears against a reference or the
  song's style; Mixology's Analyze Mix / Auto Mix balances every track and moves Cubase's faders; Masterology's
  Auto-Master masters to a goal or a reference track. Rackaholic has auto threshold / gain on one compressor.
- **It works across the whole song.** One style for all three plug-ins, the beat's key shared with every vocal and
  Honey Tune, Unmask making room in the beat for the vocal, Vocal Pocket, the Rack seeing (and now changing) every
  plug-in on every track, warnings when two plug-ins fight.
- **Honey Tune** edits notes on the clip (ARA, like Melodyne) with drift / vibrato control per note. Rackaholic's Tune
  is scale-locked auto-tune only.
- **A whole suite:** vocals, every track's processing, the full mix and the master.

### Where Rackaholic is ahead (our gaps)

| Gap | Rackaholic | Sonicology today | Worth doing? |
| --- | --- | --- | --- |
| Listen to what a module removes | De-esser monitor, Delta on Quell / Clipper | Not in Voxology's de-esser, Noise, Room, Smooth | **Yes, first.** Small, and it teaches a novice what each tool does |
| Character choice | 14 compressor styles, FET, opto, 31 delays, 63 reverbs | One compressor design, Tape / Tube / Clip saturation, one delay, one reverb (Mixology's Space: 7 effects) | Yes: a few well-made styles (FET, opto, plate / hall / room) beat many |
| A big EQ | 24 bands, dynamic per band, mid / side, linear phase, full-screen | Voxology: 5 fixed bands + 4 dynamic; Mixology: 6 bands | Yes, for the mix and master more than the vocal |
| Air / exciter, clipper, limiter in the vocal chain | Yes | Not in Voxology (Masterology has them for the master) | Small to medium |
| Order your own chain | Drag to reorder, up to 6 of each | Fixed order (13 cells, chosen for good results) | Maybe later: a fixed, smart order is easier for a novice |
| Neural voice / room / noise separation | Yes | Classic noise and room reduction (well measured, no AI model) | Big project; later |
| Undo / redo inside the plug-in | Yes | Undo of Auto-Edit / presets only | Yes, with the Rack's UNDO |
| UI scale buttons | 80 - 125 % | Free window resize | Fine as is |
| Price / one plug-in | $49.99, one product | A suite (not priced yet) | A business choice |

### How to really be the best

Claims on YouTube don't make a plug-in the best; ears do. Two things will tell us:

1. **A blind shoot-out.** The same dry vocals (rap, sung, a noisy home recording) through Voxology's Auto-Edit and
   through Rackaholic's factory chains (and the usual leaders: iZotope Nectar, a Waves vocal chain), matched in
   loudness, played blind to the user and the beta testers. Where Voxology loses, we know exactly what to fix.
2. **The beta testers' first ten minutes.** Where a producer friend gets stuck is worth more than any feature list.
